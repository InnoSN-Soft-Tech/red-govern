# Gemini CLI Context

Follow `AGENTS.md` as the repository-wide source of working rules.

Use `agent-skills/red-govern/SKILL.md` and the canonical problem map when the
task concerns Amazon Redshift governance. Do not copy command or capability
catalogues into this context file.

Red-Govern does not perform destructive remediation. Never request credentials
or unredacted production outputs. Do not invent Red-Govern commands, flags, or
capabilities.

Gemini may combine hierarchical context files, so keep this root adapter thin
and non-conflicting.
